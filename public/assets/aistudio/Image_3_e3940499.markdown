## Brand & Style

This design system is engineered for researchers, ML engineers, and data scientists evaluating algorithmic recommendation models against standardized academic benchmarks (e.g., MovieLens, Netflix Prize, Mind, KuaiRec). The core personality is rigorous, dispassionate, authoritative, and microscopically clear. 

The aesthetic is Modern Technical Minimalism grounded in deep navy architectural planes. It operates under a strict zero-image constraint—relying entirely on semantic typography, exact spatial geometry, structured data density, and crystalline micro-borders rather than photographic movie posters or marketing flourishes. Every pixel communicates statistical confidence, comparative latency, loss metrics, and categorical hierarchy.

## Colors

The palette leverages a deep navy spectral range that establishes spatial depth while maintaining optimal contrast for long research sessions.

- **Base Canvas (`#0A0F1D`):** The absolute background, absorbing light and eliminating eye strain.
- **Surface Elevation (`#0F172A`):** Tabular containers, analytic cards, and panel structures.
- **Surface Active / Elevated (`#1E293B`):** Modals, flyout inspectors, and hovered row states.
- **Structural Borders (`#334155`):** 1px structural dividers and cell demarcations with controlled low-luminance contrast.
- **Primary Analytic Accent (`#38BDF8` - Cyan):** Precision vector for active algorithmic runs, benchmark frontiers (NDCG, Recall@K, MAP), and focused inputs.
- **Secondary Metric Accent (`#818CF8` - Soft Indigo):** Secondary candidate baselines, statistical significance indicators, and ablation variations.
- **Rating & Benchmark Gold (`#F59E0B` - Amber):** Ground-truth rating values, star baselines, Pareto optimal flags, and critical warnings.
- **Text Tiers:** Highest tier white (`#F8FAFC`) for primary scores, muted slate (`#94A3B8`) for secondary labels, and structural slate (`#64748B`) for units and timestamps.

## Typography

The typographic hierarchy enforces a division of labor:
1. **Inter** handles linguistic prose, structural navigation, contextual descriptions, and metadata headers. Its tracking is tightened slightly at display sizes for an authoritative, publication-ready feel.
2. **JetBrains Mono** governs all empirical values: model weights, run hashes, dataset IDs, ranking positions ($k \in [1, 10]$), $p$-values, NDCG/HR/MRR values, and matrix dimensions.

All numerical comparisons must use tabular figures (`font-variant-numeric: tabular-nums`) to preserve column alignment across real-time benchmark tables.

## Layout & Spacing

Layouts follow a structured 12-column fluid grid tailored for heavy multi-parameter density.

- **Canvas Limits:** Max layout width caps at `1600px` to maintain dense scannability without horizontal divergence.
- **Breakpoints:** Mobile (`< 768px`, 4 columns), Tablet (`768px – 1199px`, 8 columns), Desktop (`≥ 1200px`, 12 columns).
- **Tabular Rhythms:** Benchmark tables and matrix grids prioritize compact vertical pacing (`0.5rem` to `0.75rem` row heights) to maximize visible comparative runs above the fold. 
- **Reflow Rules:** Complex evaluation matrices degrade gracefully from multi-column split views on desktop to vertically stacked model inspect panes on mobile, maintaining pinned metric headers.

## Elevation & Depth

Visual hierarchy rejects faux-physical drop shadows in favor of a layered **structural perimeter system**:

- **Tonal Planes:** Elevation is dictated by surface luminance. The base canvas (`#0A0F1D`) sits beneath cards and analytical surfaces (`#0F172A`), with interactive rows and active panels lifting to `#1E293B`.
- **Low-Contrast Micro-Borders:** All panels, metric chips, and tables are defined by a crisp 1px border (`#334155`). Overlapping panels use higher-luminance borders (`#475569`) rather than heavy blurred shadows.
- **Surgical Glows:** Highly isolated analytical focuses (e.g., active Pareto boundary point, selected algorithm run) receive a razor-thin outer glow: `box-shadow: 0 0 0 1px #38BDF8, 0 0 12px -2px rgba(56, 189, 248, 0.25)`.

## Shapes

The design uses a restrained `Soft` geometry (`0.25rem` / `4px` base radius) communicating engineering precision and institutional rigor:

- **Cards, Panels, and Containers:** `rounded` (`4px`). Retains strict spatial alignment without the visual playfulness of large radiuses.
- **Data Badges, Chips, and Metric Pills:** `rounded` (`4px`) with monospaced contents.
- **Buttons and Inputs:** Uniform `4px` corner curvature.
- **Circular Indicators:** `rounded-full` is reserved solely for status beacons (e.g., run health, node availability, training progress pings).

## Components

### Tabular Cards & Metric Containers
- Containers utilize `#0F172A` background with a mandatory `1px solid #334155` outline.
- Header bands separate from content with a `1px solid #334155` horizontal border, containing the dataset/split label in `label-mono` and sample sizes ($N$) in `#94A3B8`.
- Card actions (export CSV, diff run, seed toggle) sit flush within the right side of the header.

### Dense Data Tables
- **Row Anatomy:** Alternating or bordered rows with subtle `#1E293B` hover states. Row height is strictly constrained to `36px` for dense data absorption.
- **Cells:** Quantitative metric values (Recall@20, NDCG@10, Coverage, Serendipity) align right in `metric-sm` JetBrains Mono. Movie identifiers and model run names align left in `Inter` with trailing code tags for model versions.
- **Top Rank Highlights:** Top performing scores receive high-contrast `#F8FAFC` color with a subtle primary color accent pip (`#38BDF8`).

### Buttons & Run Selectors
- **Primary Action (Run Benchmark):** `#38BDF8` background with `#0A0F1D` bold text. On hover, shifts to slightly deeper sky blue with subtle glow.
- **Secondary Action (Baseline Comparison):** `#0F172A` base, `1px solid #334155` border, `#F8FAFC` text. On hover, border updates to `#38BDF8`.
- **Text/Ghost Buttons:** Transparent background with `#94A3B8` text, shifting to `#F8FAFC` on hover.

### Analytical Chips & Tags
- Height: `20px`. Padding: `0 6px`. Font: `JetBrains Mono` at `11px`.
- **Algorithm Type Chip (e.g., VAE-CF, LightGCN, Item2Vec):** Dark indigo tint `#1E1B4B` border `#818CF8` text `#C7D2FE`.
- **Ground-Truth / Rating Chip:** Dark amber tint `#451A03` border `#F59E0B` text `#FDE68A`.
- **Dataset Split Tag (e.g., `test-cold-start`):** Slate tint `#1E293B` border `#475569` text `#CBD5E1`.

### Zero-Image Movie Identifier Component
- Strictly zero poster thumbnails. 
- Represent items as:
  `[tt0110912] Pulp Fiction (1994) • Crime/Drama • Avg 4.3`
  Item ID rendered in `JetBrains Mono` (`#818CF8`), title in `Inter Medium` (`#F8FAFC`), release year and genres in `#64748B`, with the benchmark rating value flagged in `#F59E0B`.

### Form Inputs & Parameter Sliders
- Background: `#0A0F1D`. Border: `1px solid #334155`. Focus: `1px solid #38BDF8` with zero default browser outline.
- Hyperparameter numeric inputs (learning rate, latent factors $d$, negative samples $k$) enforce monospaced values with small increment steppers integrated directly into the border frame.
